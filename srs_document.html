1. Introduction

1.1 Purpose

The purpose of this Software Requirements Specification (SRS) document is to provide a complete, clear, and authoritative description of the functional and non-functional requirements for NextStore. This document specifies the operational capabilities, architectural structure, data flow, user interaction models, and delivery workflow required to build the NextStore web application.

1.2 Scope

NextStore is an all-in-one digital web platform designed for student, parent, and educational commerce. The application features:

  • Curriculum-Based Book Finder: Enables users to select City, School Name, and Class grade to view and purchase the prescribed school book list.
  • Extra-Curricular Activity & Coach Booking: Allows users to select sports and book personal coaching sessions.
  • School Supplies & Customization Hub: Offers stationery, school uniforms, sports equipment, and customized school bags (with student name/logo print).
  • Direct Home Delivery Information Capture: Captures user contact details (name, phone number, and physical delivery address) for home delivery.
  • Data Management Admin Dashboard: An administrative panel dedicated exclusively to adding new items (schools, books, products, coaches) and deleting obsolete data records.

2. Overall Description

2.1 Product Perspective

NextStore operates as an independent web application, providing an intuitive e-commerce experience for educational supplies and personal sports coaching bookings.

2.2 Product Functions

  1. Hierarchical Book Selection: Cascade dropdowns (City → School → Class) to view and order prescribed books.
  2. Personal Coach Booking: Select sports activities, view coach profiles, and book session slots.
  3. Stationery & Equipment Catalog: Browse and purchase pens, pencils, uniforms, bags, and sports gear.
  4. Customized Bag Engine: Input student name, class, or logo for bag personalization.
  5. Home Delivery Address Entry: Checkout form gathering full name, contact number, and home delivery address.
  6. Add & Delete Admin Panel: Admin panel for inserting new catalog entries/schools/coaches and deleting existing items.

2.3 User Classes and Characteristics

User RoleDescription & Privileges
Parents / Students (Customers) Browse book lists by school/class, select stationery/uniforms/bags, book coaches, and submit home delivery orders with contact details.
Store Administrators Access Admin Dashboard to Add New Data (schools, book sets, products, coaches) and Delete Data.

2.4 Operating Environment

  • Client Side: Cross-browser compatibility across Google Chrome, Safari, Mozilla Firefox, Edge, and mobile web browsers.
  • Server Side: Node.js / Python application connected to a SQL/NoSQL Database.

2.5 Design & Implementation Constraints

  • Responsive mobile-first user interface.
  • Admin panel UI must provide confirmation prompts before executing delete operations.

3. System Features & Specific Requirements

3.1 School & Class Books Selection Module

3.1.1 Functional Requirements

  • FR-BK-01 (Cascade Selector): Provide 3 linked dropdown selectors:
    1. City Selection
    2. School Name (filtered based on chosen city)
    3. Class / Grade (e.g., Nursery to Class 12)
  • FR-BK-02 (Booklist Display): Display the exact list of textbooks, notebooks, and reference books prescribed for the selected school and class.
  • FR-BK-03 (Kit Selection): Option to select the complete class book kit or select individual items.

3.2 Extra-Curricular Activity & Personal Coach Booking System

3.2.1 Functional Requirements

  • FR-CH-01 (Activity Categories): Display sports categories (Cricket, Football, Tennis, Swimming, Badminton, Chess, etc.).
  • FR-CH-02 (Coach Information): Show coach profile, specialization, experience, rates, and rating.
  • FR-CH-03 (Slot Booking): Select date, time slot, and preferred location for coaching.

3.3 Stationery, Uniforms & Customized Bags Catalog

3.3.1 Functional Requirements

  • FR-ST-01 (Stationery Catalog): Browse pens, pencils, notebooks, geometry boxes, and art materials.
  • FR-UN-02 (Uniform Selector): Filter uniforms by school name, gender, uniform type, and size chart.
  • FR-BG-03 (Customized Bag Studio): Real-time text preview allowing users to enter student name and select font/style to customize school bags.
  • FR-EQ-04 (Sports Gear): Catalog of sports equipment and protective gear.

3.4 Advanced Search & Multi-Attribute Filters

  • FR-SR-01 (Search Bar): Keyword search across books, stationery, uniforms, bags, and sports gear.
  • FR-SR-02 (Filters): Filter products by price, brand, category, and school name.

3.5 Checkout & Home Delivery Address Module

3.5.1 Functional Requirements

  • FR-DL-01 (Delivery Contact Information Capture): The checkout form shall collect:
    • Full Recipient Name
    • Primary Mobile Contact Number & Alternate Phone Number
    • Complete Home Delivery Address (House/Flat No, Building/Street, Landmark)
    • City, State, and Pincode
    • Delivery Instructions / Address Notes
  • FR-DL-02 (Home Delivery Order Submission): Submit order details and recipient contact address for doorstep delivery.

3.6 Admin Dashboard (Add & Delete Management)

The Admin Dashboard provides management capabilities strictly focused on Adding New Data and Deleting Existing Data across all platform modules.

3.6.1 Functional Requirements

ModuleAdd Data FunctionalityDelete Data Functionality
School & Book Management Add new Cities, Schools, Class levels, and associate Book Lists to specific classes. Delete obsolete Cities, Schools, Class mappings, or individual Book entries.
Coach & Activity Management Add new sports categories and register new Coach profiles with rates and slots. Delete inactive Coaches or removed Sports categories.
Stationery & Supplies Add new stationery items (pens, pencils, notebooks) with prices and details. Delete discontinued stationery products.
Uniforms & Customized Bags Add new Uniform designs/sizes and Bag models available for customization. Delete out-of-stock Uniform sizes or phased-out Bag models.
Sports Equipment Add new sports gear, equipment items, images, and pricing. Delete obsolete or unavailable sports equipment entries.

4. Non-Functional Requirements

4.1 Performance Requirements

  • Page load time under 1.5 seconds.
  • Immediate response for Add and Delete operations in the Admin Panel.

4.2 Security Requirements

  • Role-Based Access Control (RBAC) ensuring only authenticated Admins can perform Add/Delete actions.
  • Secure data validation on all form submissions.

4.3 Reliability & Usability

  • Confirmation modal dialogs required before performing any permanent Delete operation in the Admin Panel.
  • Simple checkout form for home delivery requests.

5. Database Data Model Overview

Core entity relations for NextStore:

  • User Entity: UserID, Name, Email, Phone, Role (Customer/Admin)
  • School Entity: SchoolID, City, SchoolName, Address
  • BookSet Entity: BookSetID, SchoolID, ClassGrade, BookTitle, Author, Price
  • Product Entity: ProductID, SKU, Name, Category (Stationery/Uniform/Bag/Sports), Price, Details
  • Coach Entity: CoachID, Name, SportCategory, Specialization, Rate
  • DeliveryOrder Entity: OrderID, RecipientName, ContactPhone, FullAddress, City, Pincode, OrderDetails, CreatedAt
